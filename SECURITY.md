# Security

If you have found a security issue in this package, please report it privately through
GitHub's [private vulnerability reporting](https://github.com/timonweb/wagtail-streamfield-presets/security/advisories/new)
rather than opening a public issue. I'll work with you to confirm and patch it, and credit
you in the release notes unless you'd rather not be named.

Security fixes are released for the latest version only.
